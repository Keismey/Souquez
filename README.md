# Souquez !

Jeu de rythme mobile (paysage) de Keismey Studio : tu es le capitaine d'un cuirassé et tu diriges ton équipage au son du tambour.

Prototype en formes simples, en attendant la direction artistique.

- Jouer : https://keismey.github.io/Souquez/
- Clavier pour tester sur ordinateur : `j` = BOUM, `f` = TAK, `d` = DING.
